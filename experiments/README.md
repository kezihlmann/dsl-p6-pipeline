# Experiment Archive

This folder preserves experiment-specific code and lightweight metadata.

## Contents

- `nerfacto_initialized_3dgs_t1902_hybrid/`: timestep 1902 hybrid initialization experiment for 3DGS, using COLMAP points plus Nerfacto points.
- `3dgs_loss_experiments/`: scripts to patch Wheat-3DGS for mask loading and run masked RGB / alpha-silhouette loss experiments.
